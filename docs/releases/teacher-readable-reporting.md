# Teacher-readable development reporting

Opening Evidence & application previously expanded the full evidence appendix automatically. A teacher encountered every technical chart for every capability before receiving a useful explanation.

The shared report now leads with one selected capability: what changed, practical use, use elsewhere and the next teaching/support action. The full evidence report remains a closed, keyboard-accessible disclosure. Changing capabilities changes the explanation and charts together.

The school overview uses a two-column capability summary with assessed improvement counts, horizontal bars and the practical support question. The six-column measurement table, individual capability exploration and group heatmap remain available on request. Participation and activity records sit under Learning & implementation in a separate disclosure. New example visitors start with the school audience; explicit learner, facilitator and funder links retain their purpose.

Canonical capability names, calculation rules, evidence classes, privacy rules, actual data and PDF evidence appendices remain intact. An aggregate report cannot name the learners needing support. Learner Development Intelligence remains the individual support product. The example remains visibly fictional, including in exported PDFs.

Verification covers school default and explicit funder entry, capability selection, hidden/open technical detail, keyboard access, back navigation, refresh and overflow at 360, 430 and 1280 pixels, plus the existing four-audience and programme-decision workflows.

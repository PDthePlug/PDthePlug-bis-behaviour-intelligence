# Continuous workbook canvas

The learner page is the learning surface. ProgrammePlayer and Universal Lab investigations use the existing shared learner-document system as one continuous workbook canvas, with a consistent reading gutter across the title, purpose, narrative, questions, evidence tables and page actions.

The page has no outer rounded card, outline or shadow. Outcomes and timing sit in the editorial flow rather than badges. Notes, Lab handovers, daily evidence sections and reference disclosures use whitespace and restrained rules rather than separate panels. Fields keep visible boundaries, touch targets, selected states, labels and keyboard focus. Tables keep their authored row and column relationships and their local horizontal scrolling on narrow screens.

The obsolete desktop reader sidebar grid is removed from the shared reader, because the programme map already lives inside the workbook. The catalogue, operational staff screens and application Menu retain their existing responsibilities. This is a presentation change: authored content, semantic field identifiers, response persistence, sharing, calendar gating and nine-investigation/ten-touchpoint sequences are unchanged.

Reference inspection included the supplied Volume 1, 2 and 3 workbook PDFs, including mission/narrative and table layouts. Their content was not modified or reinterpreted.

Verification uses the existing real journey cases, including save, Back, refresh, no-opportunity evidence, table relationships and privacy. The two existing shared-surface browser checks now assert a square page canvas, replacing their former rounded-card expectation, and capture Learn/Lab screenshots at all three supported viewports. Release verification results are recorded in the implementation pull request.

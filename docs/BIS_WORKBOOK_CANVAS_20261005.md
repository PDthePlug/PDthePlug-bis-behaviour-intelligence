# Continuous workbook canvas

The learner page itself is the learning surface. ProgrammePlayer and Universal Lab investigations share the learner-document system and a consistent reading gutter. The outer page has no floating card outline or shadow.

The canvas contains the established cards, callouts, badges, table framing, evidence sections and navigation treatments. These retain their previous surfaces, borders, corner radii and spacing. Making the page the canvas does not mean flattening the cards within it.

The Programme Map is the first card above the lesson header and remains collapsible. Its controls retain page selection, progress and browser-history behaviour. The redundant Exit reader link is removed; the centred application Menu provides navigation. Facilitator return controls remain in the application chrome.

Authored content, semantic field identifiers, response persistence, sharing, calendar gating and the nine-investigation/ten-touchpoint sequences are unchanged. Tables preserve their relationships and local horizontal scrolling. Fields preserve visible boundaries and keyboard focus.

The existing shared-surface browser checks verify the page canvas, restored card treatment, Programme Map position and keyboard/page navigation across 360, 430 and 1280 pixels. Release verification results are recorded in the implementation pull request.
